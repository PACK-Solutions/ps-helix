Démonstration Interactive

Les deux composants ci-dessous ne changent pas : seules leurs chaînes par défaut changent. Les valeurs françaises viennent de PSH_FRENCH_DEFAULTS, exportée par la bibliothèque.

Ouvrir la modale

Les libellés des boutons et celui de la croix suivent la langue choisie.

Une application en français

Les défauts de la bibliothèque sont en anglais. Une ligne les remet tous en français — 49 chaînes, dont l'exhaustivité est vérifiée en intégration continue. 

import { bootstrapApplication } from '@angular/platform-browser';
import { provideHelix, PSH_FRENCH_DEFAULTS } from 'ps-helix';

bootstrapApplication(AppComponent, {
  providers: [provideHelix({ components: PSH_FRENCH_DEFAULTS })],
});

Pour n'en changer qu'une, fusionnez plutôt que de remplacer :

provideHelix({
  components: {
    ...PSH_FRENCH_DEFAULTS,
    modal: { ...PSH_FRENCH_DEFAULTS.modal, confirmLabel: 'Envoyer' },
  },
})

Une autre langue, ou une langue qui change

Passez les chaînes depuis votre propre catalogue. Une valeur peut être une fonction, relue à chaque évaluation : un sélecteur de langue met alors à jour les composants déjà affichés. 

const t = inject(TranslateService);   // ngx-translate, transloco, $localize, le vôtre…

provideHelix({
  components: {
    select: { placeholder: () => t.instant('psh.select.placeholder') },
    modal: { dismissLabel: () => t.instant('psh.modal.close') },
  },
})

Une chaîne simple est lue une fois, à la construction du composant — ce qu'il faut pour une langue fixée au démarrage, et le cas courant. Une fonction est relue à chaque besoin, donc tout ce qu'elle lit qui est un signal fait suivre le libellé.

Élément par élément

Un input l'emporte toujours sur la configuration, et le pipe de votre bibliothèque i18n fonctionne comme sur n'importe quel autre attribut : 

<psh-select [placeholder]="'psh.select.placeholder' | translate" />

Ce qui a changé en 7.0.0

TRANSLATION_PROVIDER, NgxTranslateProvider et provideTranslation() sont retirés, ainsi que la peerDependency @ngx-translate/core. Aucun composant ne les injectait jamais : c'était un emballage autour de ngx-translate qui plaçait ce paquet dans le graphe d'import du point d'entrée, donc chaque consommateur portait la dépendance pour un service que la bibliothèque n'utilisait pas.

Les applications qui utilisent ngx-translate continuent : elles importent TranslateModule et le pipe | translate directement, comme cette démo. Ce qui change, c'est que les chaînes de la bibliothèque sont atteignables sans lui.

La liste complète

Les 226 défauts configurables, dont les 49 traduisibles, sont documentés dans CONFIGURATION.md, généré depuis les tokens eux-mêmes. Un défaut traduisible ajouté à un composant et absent du preset français fait échouer la CI : un preset en retard d'une chaîne est pire que pas de preset, puisque la page a l'air traduite et qu'un libellé au milieu est en anglais.

Bonnes Pratiques

  • Appelez provideHelix() une fois, au bootstrap, plutôt que de répéter un attribut sur chaque élément.
  • Partez de PSH_FRENCH_DEFAULTS et fusionnez vos écarts, plutôt que de recopier les 49 chaînes.
  • Réservez la forme fonction aux applications qui changent de langue sans recharger : une chaîne simple ne coûte rien.
  • Les aria-label se traduisent comme le reste — ce sont des chaînes visibles pour qui utilise un lecteur d'écran.
