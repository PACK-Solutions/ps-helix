La règle

Un TemplateRef remplace le contenu d'un élément, jamais l'élément. role="option", aria-selected, aria-sort, le roving tabindex et le clavier restent au composant — et un en-tête personnalisé reçoit toggleSort en callback plutôt que de câbler le tri lui-même. Sans cela, le mode d'échec est un consommateur qui livre un <div> ne répondant qu'à la souris.

select.optionTemplate

Le rendu d'une option était figé : icône, label, description, et rien d'autre. Afficher un avatar ou un badge imposait ::ng-deep.

{{ option.label }} {{ option.description }} @if (selected) { } 
{{ selectSnippet }}

table — headerTemplate, emptyTemplate, rowClass

L'en-tête était figé, l'état vide limité à une string, et styler une ligne conditionnellement passait par un sélecteur nth-child deviné de l'extérieur.

{{ column.label }} @if (sort) { }

{{ message }}

@if (searchTerm) {

Aucune ligne ne contient « {{ searchTerm }} ».

}

Tapez dans la recherche pour voir l'état vide, et triez : le bouton de tri reste accessible au clavier et aria-sort reste posé, alors que l'en-tête est entièrement le vôtre. 

{{ tableSnippet }}

alert — le slot d'action

Une alerte n'avait qu'une zone de message. Un bouton « Réessayer » aligné à droite, le motif le plus courant qui soit, était impossible.

{{ retried() ? 'Relancé' : 'Réessayer' }} 
{{ alertSnippet }}

menu et tab-bar — itemTemplate

Les items de psh-menu et psh-tab-bar étaient entièrement figés par leurs interfaces. Ils reçoivent le même traitement : 

{{ menuSnippet }}

withLabel est faux quand le menu est replié en mode icônes : le contexte vous dit ce que le composant sait, pour que votre template n'ait pas à le deviner.

Les sept

  • select.optionTemplate — contexte : l'option, selected, disabled.
  • table.headerTemplate — la colonne, sort, toggleSort.
  • table.emptyTemplate — le message résolu, searchTerm.
  • table.rowClass — une fonction de la ligne vers une classe.
  • menu.itemTemplate — l'item, index, withLabel, expanded.
  • tab-bar.itemTemplate — l'item, index, active.
  • Slot [psh-alert-actions] — projection, pas template.

Pourquoi le composant garde l'enveloppe

Un template qui remplacerait l'élément entier remplacerait aussi son role, son aria-selected, son tabindex et ses gestionnaires clavier. Le mode d'échec n'est pas théorique : le tri de psh-table n'était pas atteignable au clavier avant la 6.2.5, et rendre le <th> lui-même templatable aurait rouvert exactement ce défaut chez chaque consommateur. D'où toggleSort passé en callback.

La suite de tests extensibility.spec.ts asserte les deux moitiés pour chacun : que le contenu personnalisé est bien rendu, et que l'ARIA a survécu.

Bonnes Pratiques

  • Servez-vous du contexte plutôt que de recalculer : selected, sort, withLabel sont ce que le composant sait déjà.
  • Ne posez pas de role dans un template : celui de l'enveloppe est déjà correct, et un second le casserait.
  • rowClass est une fonction pure de la ligne — elle est appelée à chaque rendu.
  • Pour la couleur d'un badge ou d'un tag hors des sept valeurs sémantiques, passez par la custom property du composant plutôt que par un template.
